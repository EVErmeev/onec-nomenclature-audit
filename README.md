# Контроль заполнения номенклатуры

Диагностический отчёт для **1С:Управление торговлей, редакция 11** (версия 11.5.22.129).

Разработан в рамках тестирования MCP-интеграции OpenCode с 1С. Все объекты, реквизиты и запросы подтверждены через MCP.

---

## Назначение

Анализ справочника Номенклатура на предмет проблем заполнения данных — пустые реквизиты, дубли, пометки удаления, элементы вне групп.

---

## Системные требования

| Компонент | Требование |
|---|---|

| Конфигурация | Управление торговлей, редакция 11 |
| Режим | Управляемое приложение |

## Порядок сборки

1. Откройте 1С в режиме **Конфигуратора**
2. **Файл → Новый → Внешний отчёт**
3. В свойствах укажите:
   - Имя: `КонтрольЗаполненияНоменклатуры`
   - Синоним: `Контроль заполнения номенклатуры`
4. Создайте **основную форму отчёта** (управляемую)
5. Скопируйте содержимое `NomenclatureAudit_ObjectModule.bsl` в **модуль объекта**
6. Скопируйте содержимое `NomenclatureAudit_FormModule.bsl` в **модуль формы**
7. На форме разместите:
   - **Табличный документ** с именем `Результат`
   - **Флажок** `УчитыватьПомеченныеНаУдаление` (тип Булево)
   - **Флажок** `УчитыватьГруппы` (тип Булево)
   - **Флажок** `ТолькоСПроблемами` (тип Булево)
   - **Поле ввода** `МаксимальноеКоличествоСтрок` (тип Число)
   - **Кнопку** «Сформировать» с командой `Сформировать`
8. Сохраните внешний отчёт как `NomenclatureAudit.erf`

---

## Порядок установки

1. Скопируйте `NomenclatureAudit.erf` на компьютер с 1С
2. В пользовательском режиме: **Файл → Открыть → выбрать .erf**
3. Или в Конфигураторе: загрузите в расширение конфигурации

---

## Порядок запуска

1. Откройте внешний отчёт в 1С
2. Настройте параметры:
   - Учитывать помеченные на удаление
   - Учитывать группы
   - Только с проблемами
   - Максимальное количество строк (по умолчанию 1000)
3. Нажмите **«Сформировать»**

## Реализованные проверки (16)

### Обязательные
- Пустое наименование
- Элемент помечен на удаление
- Дубликаты наименований
- Дубликаты кодов
- Элемент вне группы

### Дополнительные
- Артикул, Вид номенклатуры, Единица измерения, Ставка НДС
- Товарная категория, Группа фин. учёта, Тип номенклатуры
- Наименование для печати, Код для поиска
- Производитель, Ценовая группа

### Исключённые
- Штрихкод — отдельный справочник `ШтрихкодыУпаковокТоваров`
- Серия — справочник `СерииНоменклатуры`
- Характеристика — справочник `ХарактеристикиНоменклатуры`
